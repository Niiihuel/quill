# quill

A native desktop app, in Rust with [limn](https://github.com/Niiihuel/limn), for working with coding agents: pick a coding-agent CLI (Claude Code first; Codex, OpenCode, Grok and others through adapters) and drive it in local sessions, with permissions, a per-request record of what changed, diffs and a terminal.

Status: specification. Read [`docs/spec.md`](docs/spec.md), then [`docs/plan.md`](docs/plan.md).

quill is not affiliated with Anthropic or any other agent vendor. It talks to the agent CLIs the user has installed and signed in to, and uses no code, fonts, icons or branding of their vendors.

## quill-ide

`apps/quill-ide` is a second, separate binary: a code reader and editor in quill's look (`crates/quill-components`), keyboard first, with limn's Vim mode. `cargo run -p quill-ide -- [folder | file]`. Files open in Vim's Normal mode, to read; `i` writes and Ctrl+S saves. What others write to an open file (an agent) shows within a second, unless it has changes of yours, which are kept until you choose. Keys: Ctrl+P opens a file by its name, `:42` in it (or `:` in Normal mode, or Ctrl+G) goes to line 42, `/` finds in the file (Ctrl+F without Vim keys), Ctrl+Shift+F finds in every file, Ctrl+Shift+E takes the keys to the files (j k h l or the arrows walk them, Escape goes back), the toggle shows and hides them, Ctrl+PageDown and Ctrl+PageUp go through the open ones, Ctrl+W closes one, Ctrl+, opens Settings, Ctrl+` the terminal. On a row of the files, a makes a file or folder, r renames, d moves to the trash. In the editor, Alt+Up/Down moves lines, Shift+Alt+Up/Down duplicates them, Ctrl+Alt+Up/Down adds a caret, Ctrl+/ comments, Ctrl+Shift+K deletes lines. With a language server on the PATH (rust-analyzer, typescript-language-server, pyright, taplo…): diagnostics, F12 goes to the definition, Shift+F12 lists the references, F2 renames the symbol, Ctrl+Shift+I formats, K (Normal mode) shows the hover, and words are completed as they are typed (arrows, Enter or Tab, Escape). The footer's problems open every file's errors and warnings under the editor, beside the terminal, a press away from each; F8 goes to the next one. A server that stops says so in the footer, and a press starts it again. quill and quill-ide talk over a socket in `$XDG_RUNTIME_DIR/quill` (`crates/quill-link`): quill's Open in (the folder button in the top bar, and a session's menu) lists quill-ide and the editors the desktop has a link handler for (VS Code, Cursor, Windsurf, Zed), with their own icons, as Desktop does; the changes panel and the tool cards open files in the one last chosen (quill-ide in its window of that folder), and `quill-ide folder file:line[:column]` hands the file to that folder's open window. Ctrl+L (or Ask agent in the editor's menus) sends the selection, or the file, to quill, into the message box of that folder's session, for you to ask about. On a row of the files, y, x and p copy, cut and paste. A Markdown file shows as source, preview or both (the bar over the editor, or Ctrl+Shift+M). What was open in a folder opens again with it.
